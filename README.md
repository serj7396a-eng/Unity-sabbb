# RAILRUSH Unity

Оригинальный трёхмерный раннер в ночном метро. Этот проект рассчитан на **Unity 6.3 LTS, 6000.3.29f1** с Built-in Render Pipeline. Геометрия, анимация, освещение, шейдеры, дождь, эффекты, интерфейс и звук создаются компонентами Unity. Код симуляции отделён от отрисовки.

## Запуск

Распакуйте архив, добавьте эту папку в Unity Hub и откройте её в Unity 6.3 LTS. В редакторе откройте сцену `Assets/Railrush/Scenes/NightShift.unity` и нажмите **Play**. Сцена собирает метро в режиме Play. Для сборки устройства используйте **File → Build Profiles** и установите в Unity Hub модуль нужной платформы. Сцена уже включена в список сцен сборки.

| Действие | Управление |
| --- | --- |
| Смена полосы | ← / → или A / D |
| Прыжок | ↑, W или пробел. Удерживайте клавишу для более высокого прыжка |
| Подкат и нырок | ↓ или S |
| Доска | B или Shift |
| Пауза | Esc или P |

На сенсорном экране доступны свайпы и кнопки. Чтобы прыгнуть выше, проведите пальцем вверх и подержите его на экране. Двойное касание игрового поля активирует доску.

## Физика

Симуляция работает с шагом 1/120 секунды. Курьер ускоряется и тормозит при смене полосы. В воздухе боковое управление мягче. Короткое нажатие и удержание прыжка дают разную высоту. Команда прыжка короткое время хранится в буфере до приземления, а прыжок остаётся доступен сразу после схода с края. Подкат меняет высоту корпуса. Нырок в воздухе ускоряет приземление и подготавливает подкат.

Рампы ведут на крыши поездов, доска гасит один удар, ранец поднимает к воздушным монетам. Доступны также пружинные ботинки, магнит и двойной счёт. Настройки и рекорд хранятся локально.

Код симуляции можно проверить отдельно от редактора командой `dotnet run --project Tests/PhysicsChecks.csproj` с .NET SDK 8.

## Браузерная сборка Unity

Команда **RAILRUSH → Build mobile WebGL** создаёт папку `Builds/RailrushWeb` в активированном Unity Editor с установленным модулем Web Build Support. Стартовая страница рассчитана на полноэкранное управление касаниями и ограничивает разрешение рендера на телефоне. Для публикации нужен статический HTTPS-хостинг.

Для автоматизированной сборки предусмотрен метод `Railrush.Editor.BuildRailrushWeb.Build`. Он принимает дополнительный аргумент `-railrushOutput` с путём папки сборки.

## Сборка в GitHub Actions с телефона

1. Загрузите содержимое проекта в корень репозитория в ветку `main`.
2. В браузере откройте **Settings → Secrets and variables → Actions → New repository secret**. Добавьте `UNITY_USERNAME` с почтой Unity ID и `UNITY_PASSWORD` с паролем Unity ID. Файл лицензии получают внутри задания и передают в GameCI.
3. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. Для публичных репозиториев Pages доступен на GitHub Free.
4. Откройте **Actions → Unity · Android and WebGL → Run workflow**. В завершённом запуске APK находится в **Artifacts → RAILRUSH-Android-APK**. Ссылка на игру появится в задании **Publish WebGL to Pages** после публикации.

Workflow читает Unity из `ProjectVersion.txt`. Для версии `6000.3.29f1` используются Linux-образы `unityci/editor:ubuntu-6000.3.29f1-android-4` и `unityci/editor:ubuntu-6000.3.29f1-webgl-4`. APK — сборка для установки и тестирования на ARM64, подписанная отладочным ключом Unity.
